# Security

This repository is a development source snapshot, not a production deployment approval.
Preserve operating-system protection, consent, authorization, credential validation and release gates.

Do not include real endpoint credentials, private keys, user documents, memory dumps,
internal host/account information or operational logs in public issues or pull requests.
For a security-sensitive report, use the repository's private vulnerability-reporting
feature if available, or contact the repository owner privately before sharing details.

See `doc/11-security-and-defender-guidelines.md` for the engineering baseline and
`doc/PUBLIC-SOURCE.md` for the public-source scope. A successful build, signature or
static scan does not guarantee acceptance under every Windows or endpoint-protection policy.
