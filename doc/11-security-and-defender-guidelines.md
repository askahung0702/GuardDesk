# 安全與 Defender 相容性工程基線

公開來源版安全控制。此文件不包含特定組織的現場資料，也不宣稱已符合特定企業政策、認證或完整 ASVS 驗證。

| --- | --- |
| SEC-01 | 記錄資產、資料流、威脅與信任邊界；分析標準使用者到 SYSTEM、端點到中心及檔案到特權操作。 |
| SEC-02 | 最小權限與固定結構操作；不提供任意 Shell、未驗證命令或任意 EXE 路徑。 |
| SEC-03 | 保護程式、設定、金鑰及備份；驗證 owner、ACL、reparse／hardlink、替換競態；SYSTEM 不執行使用者可寫內容。 |
| SEC-04 | 管理角色、CSRF、端點身分、撤銷、密碼雜湊、登入節流與 session 生命週期。 |

## Windows 特權與 UAC

SYSTEM 程序不保證它建立的物件 owner 就是 SYSTEM。要求 SYSTEM owner 的管道必須明確指定 owner、在同一 handle 上讀回，不符就關閉並回報。客戶端不能放寬為接受 Administrators。一般使用者 IPC 仍依其獨立 SID 契約。

回歸須包含 `source/tools/probe_remote_runtime_startup.py` 的實際成品依賴與管道契約，並將普通使用者 fixture 與真正 SYSTEM／另一管理員核准 UAC 的實機驗收分開。

MSI 派送只接受授權、用途／到期限定、重新驗簽／驗 hash 的全機 MSI，以及固定 msiexec 參數；不包含 EXE、任意命令、MST 或外部 CAB 支援。不自動重開機，不強制終止第三方安裝器以偽造完成。

## Defender 與發布

DEF-01：正式、可識別、可移除的 Windows 元件。DEF-02：保留所有防護與執行政策。
DEF-03：正式成品需要可信簽章／時間戳及私鑰治理。DEF-04：可追溯工具鏈，不以混淆或 hash 更換逃避偵測。
DEF-05：在相同防護政策下驗證完整生命週期。DEF-06：保留偵測與失敗證據，區分靜態掃描和行為／政策判定。DEF-07：發布審查不得由單一成功退出碼替代。

Defender 掃描退出碼 0 本身不代表乾淨；檢查工具需記錄明確結果與原始輸出。掃描成功、簽章或無當下告警，都不能保證以後不被偵測。被阻擋就停止擴大部署、保留證據；不自動還原隔離、加入排除或上傳私有資料。

公開來源沒有授權自動向第三方提交樣本、診斷或企業文件。正式發布須有平台、組織防護、安裝／更新／移除、實際 UAC 及效能驗收；未完成則保留為候選狀態。


## 遠端ACK與狀態格式維護

過期presented確認不得刷新影格／ACK／租約／桌面代次；可保留尚未到期且同桌面的既有確認。過期input、撤權、桌面／登入切換仍拒絕及清理，不重播舊按下，也不延長100ms或1秒限制。

輸入／媒體診斷限固定原因、飽和計數與耗時，不含按鍵值、座標、畫面或憑證，也不構成端點執行回執。狀態升版須驗初始及週期producer、全部解析器、方向／長度／保留字及整套cohort，舊格式或未知欄位仍拒絕。適用SEC-01～03／06～08／10／11及DEF-01／02／04～07。
